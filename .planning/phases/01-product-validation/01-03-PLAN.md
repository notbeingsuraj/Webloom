## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Evaluation Dataset → Pipeline | Ground truth business data (curated, not user input) |
| Demo/Report → Prospect | Prospect business info (public data, no PII beyond public records) |
| Pilot Agencies → Platform | Authenticated users, their prospect data, billing info |
| Pricing/Outreach → External | Email delivery, payment processing (Stripe), CRM webhooks |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-01 | Spoofing | Pilot agency authentication | mitigate | JWT/session auth, email verification, domain allowlist for pilot |
| T-03-02 | Tampering | Evaluation dataset integrity | mitigate | Dataset versioned in git, checksums, read-only in CI |
| T-03-03 | Repudiation | Pilot usage/billing | mitigate | Audit logs, Stripe webhook events, idempotency keys |
| T-03-04 | Info Disclosure | Sample report data | mitigate | Use only public business data, no fabricated PII, anonymize if needed |
| T-03-05 | DoS | Evaluation test suite | mitigate | Parallel test limits, resource quotas, timeout per test |
| T-03-06 | Elevation | Report share links | mitigate | Unguessable tokens, expiry, access logs, optional password |
| T-03-07 | Injection | Prompt injection from website content | mitigate | BusinessDataExtractor sanitizes HTML, structured evidence only in prompts |
| T-03-08 | SSRF | Official website crawl | mitigate | URL allowlist, private IP blocklist, DNS rebinding protection, 10s timeout |
| T-03-09 | Cost | API cost tracking | mitigate | AIService cost budgets per request, daily/monthly limits, alerting |

   - Field-level Precision: TP / (TP + FP) per field (name, phone, website, address, category, rating, hours, etc.)
   - Field-level Recall: TP / (TP + FN) per field
   - Incorrect Identity Rate: % of analyses where resolved entity ≠ ground truth entity (using EntityResolution matchType=different_entity)
   - Unsupported Claim Rate: % of claims in output with verificationStatus ≠ verified/supported (from EvidenceModels Claim.verificationStatus)
   - Analysis Success Rate: % of analyses completing without provider_unavailable or critical failure
   - Median Processing Time: p50 of end-to-end latency (request start → response)
   - Cost per Prospect: Total AI + provider API costs / successful analyses
   - Research Quality Score: ResearchQualityCalculator output (0-1) — composite of coverage, conflict rate, freshness, source independence

3. **Test Strategy** — Three layers:
   - Unit Tests: FieldNormalizer, EntityResolution, CandidatePipeline, EvidenceModels, BusinessProfile validators

     - New: test_research_orchestrator.js, test_deep_website_researcher.js, test_dossier_generation.js
   - Evaluation Tests: Run full pipeline on evaluation dataset, compute metrics, assert thresholds
     - New: test_evaluation_suite.js — runs all 20+ businesses, outputs metrics JSON, fails if thresholds not met

4. **Thresholds (P0 Gates)** — Minimum acceptable values for customer demos:
   - Field-level Precision: ≥ 0.85 for identity fields (name, address, phone, website)
   - Field-level Recall: ≥ 0.70 for identity fields
   - Incorrect Identity Rate: ≤ 0.05
   - Unsupported Claim Rate: ≤ 0.10
   - Analysis Success Rate: ≥ 0.90
   - Median Processing Time: ≤ 120 seconds
   - Cost per Prospect: ≤ $0.50

5. **Regression Gates** — CI integration:
   - Every PR: unit + integration tests (existing + new)
   - Nightly: full evaluation suite on dataset
   - Release: evaluation suite + thresholds must pass
   - Metric tracking: Store metrics history in .planning/eval/metrics_history.json for trend detection

6. **Quality Monitoring in Production** — Post-launch:
   - Sampling: 10% of analyses get human review
   - Drift detection: Compare field distributions to evaluation baseline
   - Cost monitoring: Daily cost per prospect alert if > $0.75
   - Provider health: Geoapify/API success rates, latency percentiles

7. **Existing Test Infrastructure** — Leverage and extend:

Create PRICING_HYPOTHESES.md documenting pricing strategy, experiments, and decision framework:

1. **Pricing Hypotheses** — Three tiers as experiments (per D-11):
   - Starter: $99/month — Up to 50 prospects/month, branded reports, PDF export, email support
   - Growth: $199/month — Up to 200 prospects/month, branded reports, PDF export, share links, API access, priority support
   - Agency: $399/month — Up to 500 prospects/month, all Growth features, team seats (up to 5), custom branding, dedicated support, SLA

2. **Value Metric** — Prospects analyzed/month (not seats, not features)
   - Rationale: Agencies scale by prospect volume; aligns cost with value delivered
   - Alternative considered: Per-report pricing (rejected — discourages report generation)
   - Alternative considered: Seat-based (rejected — agencies share logins, volume varies)

3. **Pilot Structure** (per D-12):
   - 60-day paid pilot at $299 flat
   - Up to 100 prospects analyzed
   - Full feature access
   - Success criteria: ≥20 prospects, ≥5 reports, ≥10 outreach emails
   - Conversion incentive: 50% off first month of chosen tier
   - Why paid: Filters tire-kickers, validates willingness-to-pay, covers API costs

4. **Experiment Design** — A/B tests for pilot cohort:
   - Pilot Price: $199 vs $299 vs $399 (random assignment)
   - Trial Length: 30 days vs 60 days
   - Onboarding: Self-serve vs. guided (1-hour setup call)
   - Metrics: Conversion rate, activation rate (≥5 prospects), NPS, support tickets

5. **Cost Structure & Margins** — Unit economics:
   - API Costs per Prospect: Geoapify (~$0.01), AI (~$0.15-0.30), r.jina.ai (~$0.01), total ~$0.20-0.35
   - Infrastructure: ~$50/month base (VPS, DB, CDN)
   - At 50 prospects/month (Starter): COGS ~$15-20, Gross Margin ~80%
   - At 200 prospects/month (Growth): COGS ~$45-70, Gross Margin ~65%
   - At 500 prospects/month (Agency): COGS ~$100-175, Gross Margin ~55%

6. **Go/No-Go Criteria for Pricing** — After 10 pilot agencies:
   - If ≥ 60% convert to paid → Keep tier structure, optimize prices
   - If 30-60% convert → Simplify to 2 tiers, adjust pricing
   - If < 30% convert → Fundamental value prop issue, revisit product
   - If pilot price $299 has < 20% uptake → Test $199 pilot

7. **Future Pricing Considerations** (P2/P3):
   - Usage-based overages: $0.50/prospect over limit
   - Annual discount: 20% off
   - Enterprise: Custom volume, SSO, SLA, dedicated infrastructure
   - White-label: Agency resells Webloom reports under their brand

8. **Competitive Anchoring** — Reference points:
   - Ahrefs/SEMrush: $99-399/month (SEO tools, not prospect intelligence)
   - Apollo/ZoomInfo: $500+/month (contact data, not digital audit)
   - Agency manual research: 30-60 min/prospect × $150/hr = $75-150/prospect
   - Webloom at 50 prospects/$99 = $2/prospect → 37-75x cheaper than manual

Reference Pricing.tsx for current pricing page, leadService.ts for prospect tracking, Stripe integration patterns from other projects.
