# Plan 02-03: Create a Model Evaluation Benchmark

## Objective
Do not select the primary model based on reputation alone. Build a small Webloom-specific evaluation dataset with at least 30 representative tasks covering:

1. Business information extraction
2. Business name and identity resolution
3. Service and product extraction
4. Price extraction
5. Contact information extraction
6. Customer review sentiment classification
7. Customer complaint clustering
8. Competitor comparison
9. Opportunity identification
10. Business report generation
11. Structured JSON generation
12. Evidence-grounded summarization

Use the same inputs across all available candidate models.

Evaluate:
- Extraction correctness
- Hallucination rate
- JSON validity
- Schema compliance
- Instruction following
- Reasoning quality
- Latency
- Token consumption
- Cost per successful task
- Failure rate

Create a model comparison report.

Do not fabricate evaluation scores when an endpoint cannot be tested.

## Tasks

### Task 1: Define Evaluation Task Categories and Schemas
- Define 12 task categories with specific input/output schemas
- Create JSON Schema for each task's expected output
- Define ground truth format for each category
- Document evaluation metrics per category

### Task 2: Create Business Information Extraction Tasks (3 tasks)
- Task: Extract business identity from Google Maps HTML
  - Input: Raw Google Maps page HTML (with business name, category, address, phone, website, hours)
  - Expected: Structured JSON with identity, contact, location, hours fields
  - Ground truth: Manually verified from official website
- Task: Extract business identity from official website
  - Input: Business homepage HTML
  - Expected: Same structured JSON
  - Ground truth: Manually verified
- Task: Multi-source reconciliation
  - Input: Two conflicting extractions (Geoapify + WebExtraction)
  - Expected: Resolved canonical profile with provenance

### Task 3: Create Business Name and Identity Resolution Tasks (2 tasks)
- Task: Match business across providers
  - Input: Two provider records (Geoapify flat, WebExtraction dotted)
  - Expected: Match score, match type, identity decision
- Task: Detect synthetic/duplicate identities
  - Input: Records with "Unknown Business", address-as-name, CID-only
  - Expected: Correct rejection/flagging

### Task 4: Create Service and Product Extraction Tasks (2 tasks)
- Task: Extract services from business description
  - Input: Business category + description + website content
  - Expected: Array of specific services with evidence snippets
- Task: Extract products from e-commerce/restaurant pages
  - Input: Menu or product page HTML
  - Expected: Structured products with prices, descriptions

### Task 5: Create Price Extraction Tasks (2 tasks)
- Task: Extract pricing from service pages
  - Input: Service page with pricing tiers
  - Expected: Structured pricing with tiers, inclusions, currency
- Task: Extract menu prices from restaurant
  - Input: Restaurant menu HTML
  - Expected: Items with prices, categories

### Task 6: Create Contact Information Extraction Tasks (2 tasks)
- Task: Extract contact from website footer/contact page
  - Input: Contact page HTML
  - Expected: Phone (E.164), email, address, social links
- Task: Extract contact from Google Maps
  - Input: Google Maps place details
  - Expected: Same contact fields with provenance

### Task 7: Create Customer Review Sentiment Classification Tasks (2 tasks)
- Task: Classify review sentiment
  - Input: Review text + rating
  - Expected: Sentiment (positive/neutral/negative) + confidence
- Task: Extract review themes
  - Input: Multiple reviews for same business
  - Expected: Clustered themes with example quotes

### Task 8: Create Customer Complaint Clustering Tasks (2 tasks)
- Task: Cluster negative reviews by complaint type
  - Input: 20+ negative reviews
  - Expected: Complaint categories with frequency, severity
- Task: Identify systemic issues from reviews
  - Input: Reviews over time period
  - Expected: Trending complaints, new vs recurring

### Task 9: Create Competitor Comparison Tasks (2 tasks)
- Task: Compare business to local competitors
  - Input: Target business + 3 competitor profiles
  - Expected: Comparison matrix (rating, reviews, services, pricing, digital presence)
- Task: Identify competitive advantages
  - Input: Business profile + market context
  - Expected: Verified advantages with evidence

### Task 10: Create Opportunity Identification Tasks (3 tasks)
- Task: Identify digital presence gaps
  - Input: Digital audit results
  - Expected: Prioritized opportunities with evidence, business impact, effort
- Task: Identify service/marketing opportunities
  - Input: Business profile + audit + competitor analysis
  - Expected: Specific recommendations with reasoning
- Task: Generate opportunity gap narrative
  - Input: All analysis results
  - Expected: Executive summary with competitive position

### Task 11: Create Business Report Generation Tasks (3 tasks)
- Task: Generate prospect intelligence report
  - Input: Complete business profile + audit + opportunities
  - Expected: Structured report sections (overview, verified intel, audit, opportunities, recommendations, next steps)
- Task: Generate personalized outreach email
  - Input: Business profile + specific findings
  - Expected: Email with subject, body, personalized fields
- Task: Generate value proposition statement
  - Input: Brand DNA + positioning
  - Expected: "For [audience] who [need], [business] is [category] that [benefit] unlike [competition]"

### Task 12: Create Structured JSON Generation and Evidence-Grounded Summarization Tasks (4 tasks)
- Task: Generate valid JSON for complex schema
  - Input: Prompt + JSON Schema (nested objects, arrays, enums)
  - Expected: Schema-compliant JSON
- Task: Evidence-grounded summarization
  - Input: Source text + question
  - Expected: Answer with inline citations to source
- Task: Multi-field extraction with provenance
  - Input: Business description + extraction schema
  - Expected: Each field with value, confidence, evidence snippet
- Task: Handle incomplete/ambiguous information
  - Input: Partial business data
  - Expected: Correct UNKNOWN/null handling, no fabrication

### Task 13: Build Evaluation Harness
- Create `apps/api/test_model_evaluation.js` test runner
- Load ground truth from `datasets/evaluation/ground_truth.json`
- Iterate over all available models (from Model Research phase)
- Run each task with each model
- Collect metrics: correctness, hallucination, JSON validity, schema compliance, instruction following, reasoning quality, latency, tokens, cost, failure rate
- Output comparison report

### Task 14: Create Ground Truth Dataset
- Manually verify expected outputs for all 30+ tasks
- Store in `datasets/evaluation/ground_truth.json` with format:
  ```json
  {
    "task_id": "extraction_01",
    "category": "business_information_extraction",
    "input": {...},
    "expected_output": {...},
    "evaluation_criteria": {...}
  }
  ```

### Task 15: Run Evaluation and Create Comparison Report
- Execute evaluation across all testable models
- Document which models could not be tested (mark UNTESTED)
- Create model comparison report with all metrics
- Write to `docs/ai-infrastructure/EVALUATION-BENCHMARK.md`
- Include recommendations for primary/secondary models per capability

## Acceptance Criteria
- [ ] 30+ evaluation tasks defined across 12 categories
- [ ] Ground truth manually verified for all tasks
- [ ] Evaluation harness runs all tasks against all available models
- [ ] Metrics collected: correctness, hallucination rate, JSON validity, schema compliance, instruction following, reasoning quality, latency, tokens, cost, failure rate
- [ ] Comparison report generated with per-model, per-task breakdown
- [ ] UNTESTED models clearly marked
- [ ] No fabricated scores
- [ ] Report written to `docs/ai-infrastructure/EVALUATION-BENCHMARK.md`
- [ ] Ground truth stored in `datasets/evaluation/ground_truth.json`
- [ ] Test runner at `apps/api/test_model_evaluation.js`
