# Plan 02-02: Open-Weight Model Research and Selection

## Objective
Research and evaluate high-quality open-weight models and their available inference providers.

**Mandatory model to evaluate:**
- **NVIDIA Nemotron 3 Ultra 550B A55B** (model identifier: `nvidia/nemotron-3-ultra-550b-a55b`, endpoint: `https://integrate.api.nvidia.com/v1`)

**Additional models to evaluate:**
1. DeepSeek V4.1 Flash
2. Qwen3.5 35B A3B (Hugging Face: `Qwen/Qwen3.5-35B-A3B`)
3. Mistral Small 4
4. GLM 5.3 Flash
5. Other relevant models from NVIDIA, Alibaba Qwen, DeepSeek, Mistral, Z.ai

For every candidate, document:
- Exact model identifier
- Model developer
- Open-weight or open-source status
- Licence
- Available hosted inference providers
- Whether free inference is genuinely available
- Whether account verification or payment details are required
- Rate limits
- Context length
- Tool-calling support
- Structured output support
- Latency
- Expected inference cost
- Production suitability
- Deployment requirements

Distinguish clearly between:
A. Free downloadable model weights
B. Free hosted inference
C. Free trial or temporary API credits
D. Paid hosted inference
E. Self-hosted inference requiring GPU infrastructure

Do not describe a model as having a free production API merely because its weights are publicly downloadable. Verify current information from official documentation wherever possible.

## Tasks

### Task 1: Research NVIDIA Nemotron 3 Ultra 550B A55B (Mandatory)
- Visit official NVIDIA model page: https://build.nvidia.com/nvidia/nemotron-3-ultra-550b-a55b
- Visit API documentation: https://integrate.api.nvidia.com/v1
- Document: API authentication method, OpenAI-compatible API support, context window, rate limits, output limits
- Document: Reasoning configuration, structured output limitations (currently not supported per docs)
- Document: Function calling compatibility, latency benchmarks
- Document: Commercial usage terms, free trial availability
- Test: Make actual API calls to verify availability and measure latency
- Evaluate: Suitability for Webloom production workloads (business research, extraction, audit, report generation)

### Task 2: Research DeepSeek V4.1 Flash

- Document: Latency, expected cost, production suitability, deployment requirements

### Task 7: Investigate Hosted Inference Providers
For each model, identify and evaluate:
- **NVIDIA NIM / NVIDIA hosted inference**: https://integrate.api.nvidia.com

- **DeepSeek API**: https://api.deepseek.com
- **Gemini API**: https://generativelanguage.googleapis.com
- **OpenRouter**: As optional routing layer

Document for each provider: authentication, pricing, rate limits, model availability, OpenAI compatibility, structured output support, geographic availability.

### Task 9: Evaluate Nemotron 3 Ultra Structured Output Workaround
Since Nemotron 3 Ultra documentation indicates structured output is not supported:
- Research JSON extraction/repair strategies (regex extraction, schema-guided parsing, iterative repair)
- Evaluate using a smaller model for structured output formatting (two-stage: Nemotron reasoning → small model formatting)
- Document recommended approach for Webloom's schema-enforced tasks
