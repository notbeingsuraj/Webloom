# Plan 02-05: Provider Adapters

## Objective
Create a consistent provider adapter interface. Each provider should implement:
- `generate(request)` - Execute inference
- `healthCheck()` - Check provider availability
- `getModels()` - List available models
- `getCapabilities()` - Return supported capabilities
- `classifyError(error)` - Normalize provider errors to standard taxonomy
- `getUsage()` - Return usage statistics
- `validateConfiguration()` - Verify provider config

Support OpenAI-compatible endpoints where possible.

**Prioritized adapters:**
1. **NVIDIA NIM / NVIDIA hosted inference** - Primary for Nemotron 3 Ultra
2. **Hugging Face Inference Providers** - Serverless API and Inference Endpoints
3. **Other verified free/low-cost hosted inference** - Together AI, Replicate, Fireworks AI, Anyscale, Groq
4. **DeepSeek API** - https://api.deepseek.com
5. **Gemini API** - Enhance existing implementation
6. **OpenRouter** - As optional routing layer, enhance existing
7. **Self-hosted OpenAI-compatible endpoints** - Ollama, LM Studio, vLLM, llama.cpp, TGI

Do not make every provider mandatory. Providers must be independently configurable and removable. Do not introduce another unnecessary gateway.

## Tasks

### Task 1: Define Provider Adapter Interface
- File: `apps/api/src/ai/providers/ProviderAdapterInterface.js`
- Abstract base class with all required methods
- Define TypeScript-like JSDoc interfaces for request/response shapes
- Standard error classification mapping
- Usage statistics schema
- Configuration validation schema

### Task 2: Create NVIDIA Provider (Primary for Nemotron)
- File: `apps/api/src/ai/providers/NVIDIAProvider.js`
- Base URL: `https://integrate.api.nvidia.com/v1`
- Authentication: Bearer token (NVIDIA API key)
- OpenAI-compatible chat completions endpoint
- Model: `nvidia/nemotron-3-ultra-550b-a55b`
- Handle structured output limitation (Nemotron doesn't support native JSON schema)
- Implement JSON extraction/repair for structured tasks
- Rate limit handling per NVIDIA docs
- Health check with minimal token probe
- Capabilities: reasoning, research, business_research, report_generation

### Task 3: Create Hugging Face Provider
- File: `apps/api/src/ai/providers/HuggingFaceProvider.js`
- Support both Serverless Inference API (free tier) and Inference Endpoints (paid)
- Base URLs: `https://api-inference.huggingface.co` (serverless), custom endpoint for dedicated
- Authentication: Hugging Face API token
- Model routing: Support any model on HF Hub
- Handle model loading delays (serverless cold starts)
- Structured output support varies by model
- Capabilities: extraction, classification, general-purpose
- Free tier limits: 30k tokens/month on serverless

### Task 4: Create DeepSeek Provider
- File: `apps/api/src/ai/providers/DeepSeekProvider.js`
- Base URL: `https://api.deepseek.com`
- Authentication: DeepSeek API key
- OpenAI-compatible API
- Models: deepseek-chat, deepseek-coder, deepseek-reasoner
- Structured output support via response_format
- Competitive pricing (~$0.14/1M input, $0.28/1M output for V3)
- Capabilities: extraction, reasoning, coding, structured_analysis

### Task 5: Enhance Gemini Provider

- Better error classification for quota/rate limits

### Task 6: Enhance OpenRouter Provider
