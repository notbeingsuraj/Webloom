# Plan 02-08: Cost and Free-Tier Optimisation

## Objective
Minimize operating expenses while maintaining quality.

**Priorities:**
1. Use genuinely free inference where suitable
2. Use smaller models for simple classification and extraction
3. Reserve large reasoning models for difficult tasks
4. Cache deterministic and repeatable results where safe
5. Avoid unnecessary repeated inference
6. Track token consumption and estimated cost
7. Apply per-task token and cost budgets
8. Prevent runaway retries
9. Provide configurable monthly spending limits
10. Allow paid providers to be disabled entirely

**Explicit transition strategy from free experimentation to controlled paid production inference.**

## Tasks

### Task 1: Implement Cost Tracker
- File: `apps/api/src/ai/CostTracker.js` (from Plan 02-04)
- Per-request tracking: provider, model, promptTokens, completionTokens, totalTokens, estimatedCostUSD
- Aggregation: daily, monthly, per-capability, per-provider, per-model
- Methods: `record(request)`, `getSummary(period)`, `getProjection()`, `getBreakdown(capability)`
- Cost estimation: use ModelRegistry costPer1MTokens or provider pricing
- Integration with QuotaManager for budget enforcement

### Task 2: Implement Quota Manager with Monthly Limits
- File: `apps/api/src/ai/QuotaManager.js` (from Plan 02-06)
- Per-provider monthly budget (USD)
- Track: currentMonthUsage, dailyUsage, requestCount, tokenCount
- Methods: `canAfford(provider, estimatedTokens, model)`, `recordUsage(provider, tokens, cost)`, `getRemainingBudget(provider)`, `resetMonthly()`
- Alerts at 80% and 95% of budget (log + optional webhook)
- Config: `AI_MONTHLY_BUDGET_USD`, `AI_PROVIDER_BUDGETS` (per-provider override)
- Allow paid providers to be disabled: `AI_DISABLE_PAID_PROVIDERS=true`

### Task 3: Cost-Aware Capability Routing
- File: `apps/api/src/ai/CapabilityRouter.js` (from Plan 02-04)
- Extend routing policy with cost constraints:
  - `maxCostPerRequest` per capability
  - `preferFree` boolean per capability
  - `costWeight` in provider selection (0-1)
- Route simple tasks (classification, extraction) to cheaper/smaller models
- Reserve expensive reasoning models (Nemotron) for `business_research`, `report_generation`
- Fallback to free tier when budget constrained

### Task 4: Model Registry Cost Metadata
- File: `apps/api/src/ai/ModelRegistry.js` (from Plan 02-04)
- Add cost fields to model registration:
  - `costPer1MInputTokensUSD`
  - `costPer1MOutputTokensUSD`
  - `freeTierAvailable` (boolean)
  - `freeTierLimits` (tokens/month, requests/minute)
  - `provider` (for pricing lookup)
- Methods: `estimateCost(model, promptTokens, completionTokens)`, `getFreeModels(capability)`

### Task 5: Implement Response Caching
- File: `apps/api/src/ai/CacheManager.js` (new)
- Cache deterministic/repeatable results
- Key: hash of (capability, prompt, model, temperature, schema)
- TTL: configurable per capability (e.g., extraction: 24h, research: 1h, audit: 6h)
- Invalidation: on model change, schema change, prompt version change
- Storage: in-memory (dev), Redis/Upstash (prod)
- Cache hit tracking for cost savings measurement
- Only cache: deterministic extractions, classification, schema-validated JSON
- Never cache: reasoning tasks with temperature > 0, evidence-grounded tasks

### Task 6: Per-Task Token and Cost Budgets
- File: `apps/api/src/ai/TaskBudgetManager.js` (new) or extend CapabilityRouter
- Define budgets per capability in config:
  ```js
  taskBudgets: {
    business_extraction: { maxTokens: 2000, maxCostUSD: 0.001 },
    business_research: { maxTokens: 6000, maxCostUSD: 0.01 },
    entity_resolution: { maxTokens: 1000, maxCostUSD: 0.0005 },
    review_analysis: { maxTokens: 1500, maxCostUSD: 0.001 },
    report_generation: { maxTokens: 8000, maxCostUSD: 0.02 }
  }
  ```
- Enforce at orchestration level: clamp maxTokens, reject if estimated cost exceeds budget
- Track budget utilization per capability

### Task 7: Prevent Runaway Retries
- Extend RetryController (Plan 02-06) with cost-aware limits:
  - Max total cost per request across all retries/fallbacks
  - Track cumulative cost in request context
  - Stop retrying if cumulative cost exceeds task budget
  - Log runaway retry attempts for alerting

### Task 8: Free Tier Optimization Strategies
- Document free tier limits per provider in ModelRegistry:
  - NVIDIA: Free trial credits, then pay-per-use
  - Hugging Face: 30k tokens/month serverless
  - DeepSeek: Free tier with rate limits
  - Gemini: Free tier with RPM/TPM limits
  - OpenRouter: Free models (meta-llama/llama-3.1-8b-instruct:free)
  - Local: Unlimited (hardware cost only)
- Implement free-tier preference logic:
  - When `preferFree: true`, route to free-tier eligible models first
  - Track free tier consumption per provider
  - Alert when free tier exhausted

### Task 9: Transition Strategy: Free → Paid Production
- Document phased approach:
  1. **Phase 1 (Free Experimentation)**: All free tiers, local models, aggressive caching. Budget: $0.
  2. **Phase 2 (Controlled Paid)**: Enable paid providers for critical capabilities only. Budget: $10-50/month. Monitor cost/quality.
  3. **Phase 3 (Production)**: Optimize model selection based on real usage. Budget: $100-500/month. Reserved instances for latency-critical paths.
- Config flags for each phase:
  - `AI_COST_PHASE=free|controlled|production`
  - Phase controls: provider enablement, budget limits, model preferences

### Task 10: Cost Monitoring and Reporting
- Add cost metrics to AIExecutionLogger (Plan 02-04)
- Daily/weekly cost summary in logs
- `/health/ai` endpoint includes cost summary
- Alert on: budget threshold, unusual cost spike, free tier exhaustion
- Cost per successful task metric (cost / successful completions)
