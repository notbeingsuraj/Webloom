## Remediation Plan

### Must fix before production (order):

1. **Implement the canonical read layer** (§2–§5, §10–§11): create
   `CanonicalBusinessProfileService` with `fromBusinessProfile(profile)`,
   `fromEntityData({entity, canonicalFields, providerIdentities})`, and
   `fromPersistedEntity(entityId)`. Deterministic, side-effect free, no DB
   writes, no AI, no provider calls. Centralize field mapping; define canonical
   name/address/phone/website/domain/coords/category/services/hours/social/rating/
   review-count resolution in ONE place.
2. **Authoritative identity + provenance rules** (§6, §8): `identity` never
   invents values (`null` when unavailable), never upgrades provenance
   (discovered stays discovered; ai_generated stays ai_generated); provider IDs
   live under `providers[]`, not `identity`.
3. **Write `test_phase_p13_canonical_profile.js`** with all 32 tests in §12, using
   **real** Geoapify flat `business.*` and WebExtraction `identity.*` fixtures
   (§13) proving both map to one canonical shape.
4. **Migrate one low-risk downstream consumer** (§14) — the phase recommends a
   single proof-of-concept; pick the narrowest read path identified in the
   business/leads/digitalAudit routes, and prove read parity.
5. **Prove the existing P1.2 guardrail still holds through the projection** — add
   a test that `ai_generated` provenance survives `fromBusinessProfile`
   unchanged (blocker for trust in the read layer).
6. **Run the §17 regression set** and report exact pass/fail counts, keeping the
   two known pre-existing canonicalization failures tracked separately.

### Should fix soon:

- Add an `AI-SPEC.md` (EVALS-SPEC) for this and future AI/identity phases
  defining rubrics and measurement approach, replacing verdict-by-inspection.
- Wire the P1.3 projection-parity suite into a repeatable test command
  (`package.json` / Makefile) so it runs in CI.

### Nice to have:

- Introduce light tracing (Langfuse/Phoenix) on the AI-extraction boundary so
  provenance and confidence decisions are auditable in production.
- Build a 10–20 record reference dataset (critical + edge cases: synthetic-name
  inputs, missing identity, disputed entity) for future LLM-judge calibration —
  not required for this deterministic read layer.
